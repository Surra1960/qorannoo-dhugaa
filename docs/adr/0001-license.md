
# ADR 0001: License

Date: 2026-10-05
Status: Accepted

## Decision

QorannooDhugaa is released under AGPL-3.0, with a separate paid commercial license available for organizations that cannot or will not comply with AGPL.

## Why

- Anyone who modifies QorannooDhugaa and runs it as a service must publish their changes, so a company cannot take the code and build a closed competing product from it.
- Because the platform handles sensitive data and promises privacy, open source code lets anyone inspect how that data is handled.
- NGOs and universities can self-host for free, which supports real-user testing and measurable impact.
- Companies that dislike AGPL can buy a commercial license, and hosting and support can also be sold.

## Condition

This model only works if the project owns the copyright to all of its code. Any outside contributor must sign a contributor agreement that allows the project to license their contribution commercially.
